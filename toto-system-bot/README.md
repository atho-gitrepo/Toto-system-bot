# Toto System 8 Automation Bot

## Quick Deploy to Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/toto-bot)

## Setup

1. Get Telegram Bot Token from @BotFather
2. Get Firebase credentials from Firebase Console
3. Set environment variables in Railway
4. Deploy!

## Commands
- /start - Activate bot
- /last - Last numbers
- /history - Last 5 generations  
- /roi - ROI statistics
